# 20 Doors: Escape the Old Mansion

Play in your browser: **https://mohammadrefayethossainmina.github.io/20-doors-escape-the-old-mansion/**

Escape an old mansion by opening 20 puzzle doors. Each door is the puzzle: tip vases, light candles in order, play a tune, turn a family crest, slide iron bolts, read a mirror backwards. No text, a 2-minute timer per door, decoy keys and fake clues, and hidden golden keyholes that unlock a secret bonus door.

Made with Unity (WebGL). Works on desktop and phones. This repository only holds the playable web build.
